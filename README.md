# Dhyey Seta Portfolio

Static, responsive portfolio for Dhyey Seta. Built with HTML, CSS, and vanilla JavaScript and ready for GitHub Pages.

## GitHub Pages

1. Open **Settings → Pages → Build and deployment**.
2. Choose **Deploy from a branch**, **main**, **/(root)**, and save.
3. Visit https://ku2407u1042-ux.github.io/Dhyey-Seta-Portfolio/

## Files

- `index.html` — webpage content
- `styles.css` — responsive design
- `script.js` — mobile menu and copyright year
- `assets/Dhyey_Seta_CV.pdf` — CV to upload as a binary file

**Important:** PDF upload is required for CV buttons to work. The repository and PDF will be publicly accessible.
